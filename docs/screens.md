# 画面設計

[requirements.md](requirements.md) の必須機能を対象にする。

## 画面一覧

| No | 画面 | 目的 | ログイン | URL | テンプレート |
|---|---|---|---|---|---|
| 1 | 投稿一覧（トップ） | 投稿を新しい順に縦1列で表示する | 不要 | `/` | `index.html` |
| 2 | 投稿詳細 | 1件の投稿を大きく表示する | 不要 | `/posts/<id>` | `post_detail.html` |
| 3 | 投稿作成 | 写真1枚とキャプションを投稿する | **必要** | `/posts/new` | `post_new.html` |
| 4 | ログイン | ユーザー名とパスワードでログインする | 不要 | `/login` | `login.html` |
| 5 | ユーザー登録 | 新しいユーザーを登録する | 不要 | `/register` | `register.html` |

すべての画面は `base.html` を継承し、共通のヘッダーとflashメッセージを表示する。

## 共通ヘッダー（base.html）

```
未ログイン:  [PhotoShare]                ログイン | 登録
ログイン中:  [PhotoShare]   user1 | 投稿する | ログアウト
```

- 「PhotoShare」をクリックすると投稿一覧へ移動する
- ログアウトはボタンにして、POSTで送信する
- ヘッダーの下にflashメッセージ（成功・エラー）を表示する

## 各画面の内容

### 1. 投稿一覧（index.html）
```
┌──────────────────┐
│ user1   10/10 12:00 │
│ [      写真      ]  │ ← クリックで詳細へ
│ キャプション        │
└──────────────────┘
（新しい順に繰り返す）
```
- 表示項目: 写真、キャプション、投稿者名、投稿日時
- 投稿が0件のとき: 「まだ投稿がありません」と表示する

### 2. 投稿詳細（post_detail.html）
- 表示項目: 写真、キャプション、投稿者名、投稿日時
- 「一覧へ戻る」リンクを置く
- 存在しないIDのときは404を返す

### 3. 投稿作成（post_new.html）
- 入力項目: 写真（jpg / png、5MBまで）、キャプション（200文字まで）
- 「投稿する」ボタンを置く
- エラーのときは同じ画面に戻り、エラーメッセージを表示する

### 4. ログイン（login.html）
- 入力項目: ユーザー名、パスワード
- 「ユーザー登録はこちら」リンクを置く
- 失敗したときは同じ画面に戻り、エラーメッセージを表示する

### 5. ユーザー登録（register.html）
- 入力項目: ユーザー名、パスワード
- 「ログインはこちら」リンクを置く
- ユーザー名が重複しているときは同じ画面に戻り、エラーメッセージを表示する

## 画面遷移

```
                 ┌──────────────┐
  登録 ─(成功)─▶ │              │ ─(投稿をクリック)─▶ 投稿詳細
ログイン ─(成功)─▶ │   投稿一覧   │
投稿作成 ─(成功)─▶ │              │ ◀─(一覧へ戻る)─── 投稿詳細
                 └──────────────┘
```

| 遷移元 | きっかけ | 遷移先 |
|---|---|---|
| 投稿一覧 | 投稿をクリック | 投稿詳細 |
| 投稿詳細 | 「一覧へ戻る」 | 投稿一覧 |
| ログイン | ログイン成功 | 投稿一覧 |
| ユーザー登録 | 登録成功（自動でログインする） | 投稿一覧 |
| 投稿作成 | 投稿成功 | 投稿一覧 |
| 未ログインで投稿作成を開く | ログインが必要 | ログイン |
| ヘッダー | ログアウト | 投稿一覧 |
| 各フォーム | 入力エラー | 同じ画面（エラーを表示） |
