# 写真共有アプリ 要件定義

## 1. アプリの概要
友人同士で旅行や日常の写真を見せ合う、インスタグラム風の写真共有Webアプリ。
- 技術: Python / Flask / PeeWee（DBはSQLite）
- 写真1枚と短いキャプションを投稿し、新しい順に一覧で見る

## 2. 想定ユーザー
- 友人同士で旅行や日常の写真を共有したい人
- **閲覧者**: ログインしていなくても投稿一覧を見られる
- **ログインユーザー**: 投稿や自分の投稿の管理ができる（追加機能を入れたら、いいねとコメントも）

## 3. 必須機能（この順番で実装する）
小さく分けた単位ごとに、動くことを確認してから次に進む。

### 3-1. ユーザー登録
- [ ] ユーザー名とパスワードで登録できる
- [ ] ユーザー名が重複していたらエラーを表示する
- [ ] パスワードはハッシュ化して保存する

### 3-2. ログイン / ログアウト
- [ ] ユーザー名とパスワードでログインできる
- [ ] 間違っていたらエラーを表示する
- [ ] ログアウトできる
- [ ] ヘッダーにログイン状態（ユーザー名、またはログインへのリンク）を表示する

### 3-3. 写真投稿
- [ ] ログインユーザーだけが投稿画面を開ける（未ログインならログイン画面へ）
- [ ] 写真1枚（jpg / png）とキャプションを投稿できる
- [ ] 写真なし、対応していない形式、サイズ超過（例: 5MB）はエラーにする
- [ ] キャプションは短め（例: 200文字まで）にする

### 3-4. 投稿一覧
- [ ] 誰でもトップページで投稿一覧を見られる
- [ ] 新しい順に並べる
- [ ] 写真、キャプション、投稿者名、投稿日時を表示する

## 4. 余裕があれば追加する機能（上から優先）
1. **自分の投稿の削除**: 投稿者本人だけが削除できる。画像ファイルも削除する
2. **キャプション編集**: 投稿者本人だけが編集できる
3. **いいね**: 1人1投稿につき1回まで。取り消せる。件数を表示する
4. **コメント**: ログインユーザーが投稿にコメントできる。一覧または詳細ページに表示する
5. **画像の縮小・サムネイル**: Pillowで縮小して、一覧の表示を軽くする
6. **アイコン画像**: 登録時やあとから設定でき、投稿の横に表示する

今回やらないこと: 検索、フォロー

## 5. 非機能要件
- **セキュリティ**: パスワードはハッシュ化する（`werkzeug.security`）。フォームはCSRF対策をする（Flask-WTF）。本人チェックはサーバー側で行う
- **アップロード**: 拡張子と画像の中身を確認する。ファイル名はサーバー側で作り直す（例: UUID）。`MAX_CONTENT_LENGTH` でサイズを制限する
- **規模**: 友人同士で使う小規模アプリを想定する。ローカル環境で動けばよい
- **使いやすさ**: スマホでも見られる簡単なレイアウトにする。エラーはflashメッセージで表示する

## 6. 実装時に注意すべきこと
- 機能は1つずつ作って、ブラウザで動作を確認してから次に進む
- `SECRET_KEY` はコードに直接書かず、環境変数などから読み込む
- アップロードした画像とDBファイルは `.gitignore` に入れる
- PeeWeeのモデルは最初に設計しておく（User / Post。追加機能で Like / Comment）。Like は (user, post) の組み合わせを重複できないようにする
- 一覧で投稿者名を表示するときは、JOINを使ってクエリの回数を増やしすぎない
- 削除や編集など状態を変える操作はPOSTで受け付ける（GETでは受け付けない）
- テンプレートは `base.html` を継承して、ヘッダーを共通化する
